## Production vs. sandbox

ExamTools has two environments:

| | Production | Sandbox |
|-|------------|---------|
| **URL** | [exam.tools](https://exam.tools) | [sandbox.exam.tools](https://sandbox.exam.tools) |
| **Purpose** | Real exam sessions | Practice and training |
| **FCC submissions** | Yes — real license grants | No — no real data submitted |
| **Login** | Your real HamStudy account | Separate sandbox account |

Use the sandbox to:
- Learn the platform before your first real session
- Train new VEs
- Test new workflows without affecting real applicants

> Sandbox accounts and production accounts are separate. A login on one does not work on the other.

## Supported browsers

ExamTools works on all modern browsers. For the best experience, use an up-to-date version of one of the following:

- Google Chrome
- Mozilla Firefox
- Apple Safari
- Microsoft Edge

Internet Explorer is not supported.
