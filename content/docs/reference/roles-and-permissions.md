ExamTools has two levels of roles: **team roles** (apply across all sessions for a team) and **session roles** (apply within a specific session).

## Team roles

| Role | Create sessions | Manage VE roster | Edit team settings | Delete team |
|------|:-:|:-:|:-:|:-:|
| **Owner** | ✓ | ✓ | ✓ | ✓ |
| **Co-owner** | ✓ | ✓ | ✓ | — |
| **VE Admin** | — | ✓ | — | — |
| **VE** | — | — | — | — |

## Session roles

| Action | Owner / Co-owner | VE Admin | VE |
|--------|:-:|:-:|:-:|
| Open / close session | ✓ | — | — |
| Add / remove applicants | ✓ | ✓ | — |
| Edit applicant info | ✓ | ✓ | — |
| Start / record exam | ✓ | ✓ | — |
| Sign forms | ✓ | ✓ | ✓ |
| Submit to VEC | ✓ | — | — |
| Generate paper exams | ✓ | — | — |
